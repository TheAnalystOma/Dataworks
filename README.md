# Dataworks
# Crime Data Cleaning and Analysis (2012–2024)

## Project Overview
This project involved cleaning and consolidating crime data provided across multiple Excel sheets into a single dataset and summarize key insights. The dataset was provided as part of a data analytics training assignment.

## Tools Used
- Microsoft Excel
- PivotTables and Charts

## Data Cleaning
- Removed blank rows and duplicate records where identified.
- Trimmed whitespace.
- Corrected spelling inconsistencies.
- Merged multiple sheets into one consolidated dataset.

## Key Findings
- Theft was the most frequently recorded offense, followed by violence against persons.
- Possession of weapons was the least frequently recorded offense.
- The Metropolitan Police area recorded the highest number of crimes.
- Recorded crime figures generally increased from 2014/2015 through 2022/2023 except for a drop in 2020/2021.

## Data Limitations
- Data loss may affect the completeness of records for Devon and Cornwall and North Yorkshire.
- The 2023–2024 figures appeared to cover only the first quarter, making direct comparison with previous years difficult.
- Missing records may affect the interpretation of observed trends.

## Deliverables
- Cleaned and consolidated crime dataset.
- Excel PivotTables and charts.
- Summary of findings and data limitations.

## Skills Demonstrated
Data cleaning, data consolidation, data quality checks, exploratory data analysis, Excel PivotTables, data visualization, and insight reporting.
